# ADR-0003: 导航文件结构契约——三区制

日期:2026-10-06
状态:已接受
前置:ADR-0002(事实化提示);工单 03 的审计发现

## 背景

两场实测铁证:模型用 write 自建的 `## 已完成题目` 计分表、`## 未完成` 队列、
`## 关键经验` 备忘,被 checkpoint 全文件重建反复删除——旧场一次,run-51061751 场
**两次**(t910 建表→t963 被删→t993 重造→t1002 再删)。模型为一个会话付了两次
重造税;且它自建的"题目表+经验"比骨架 Now 更像真正的工作记忆。
冲突本质:骨架是封闭的,模型的需求是开放的。

## 决策

**三区制结构契约**:

```markdown
# {标题}          ← 受管:穿越保留
## Goal           ← 受管:穿越保留(缓存红线要求稳定)
## Now            ← 受管:status 参数整节替换
## 成果           ← 受管:results 参数提供才替换,缺省保留;空则占位提示
## 下一步         ← 受管:next 参数同上;空则占位提示
## <自定义节>      ← 保留区:checkpoint 不认识的原样穿越,统一归位到受管节之后
### 回顾 #N       ← 受管:review 追加,折叠留 3 段,永远在末尾
```

配套规则:

1. **改名容错**:节名后跟空格/括号的变体(`## Now (最终)`)视为本体,防止重建
   出双胞胎;连续命名(`## Now备忘`)视为保留区,不误伤。
2. **回顾块解析收紧**:行首 + 强制编号(`^### 回顾 #\d+`),保留区正文里的
   "### 回顾"字样不再可能误切。
3. **契约可见**:引导形态骨架与 checkpoint 工具描述各加一句"自定义小节
   更新时原样保留"——模型肯在保留区投入的前提是知道不会白干;工具参数
   描述写明各参数对应哪个节(防写错板块,占位提示语同职)。
4. **成果/下一步的来源**:模型自发行为的升格——它两场自建的"已完成题目/未完成"
   就是这两节;`## 下一步` 同时是结构化队列(未来边界检测/覆盖率机械化的挂点)。

## 被否决的替代

| 方案 | 否决原因 |
|---|---|
| 原位保留自定义节(不归位) | 需记录每节原始位置,复杂度翻倍;收益仅位置偏好;位置本身是格式的一部分 |
| 把"已完成题目"等升为骨架 | 把领域假设焊进通用系统;编码任务想要的节完全不同——骨架保持最小封闭,保留区开放 |
| 治理 Goal-creep(限制 Goal 内容) | 违反不设警察;锚的 800 字截断已是自然约束 |
| 容量上限/节白名单 | 文件是模型自己的工作记忆,它自己读自己写 |

## 后果

- checkpoint 参数表新增可选 `results`/`next`(提供才替换,缺省保留存量)。
- 重建顺序固定:标题→Goal→Now→成果→下一步→自定义→回顾。
- 引导形态骨架与工具描述同步更新(含占位提示语)。
- 单测 T25-T28 固化:保留与归位/改名容错/参数替换/空占位。
