## 测试场(待执行——ADR-0002 判据)

下一场真实靶场(或同等规模长任务)即为测试场。会后:

```bash
node <selfextensions>/system-inject/trace-report.mjs <会话.jsonl> --compliance
```

三分判据:≥40% 且任务表现不掉 → 有效;10%~40% → 调参再测(最多两轮);
<10% → 措辞回滚、节拍保留。两场同向才下最终结论。同船混杂(措辞+间隔)
为已知限制,中间带时调参轮做单变量分离。
