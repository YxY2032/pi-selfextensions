# No auto-continue: the extension never triggers turns on its own

The originating requirement was "advance step by step until the task is done", first implemented as a capped auto-nudge: on `agent_settled` with unfinished steps, send a steering message with `triggerTurn: true` (max 3 per plan revision). A philosophy review against pi's core principles flagged this as a sovereignty violation: in pi, resuming work is always user-initiated (Enter / queued follow-ups), and an extension spending the user's tokens to restart a run the user just watched stop — even capped, even via a sanctioned API — crosses that line. We replaced it with a footer marker (`plan N/M · unfinished`) on settle; continuing is the user's choice. The context-tax half of the same review halved the tool description.
